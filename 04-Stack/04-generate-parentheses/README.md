## Problem

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses. A combination is well-formed if every open bracket has a matching close bracket in the correct order.

## Examples

**Example 1:**
```
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```

**Example 2:**
```
Input: n = 1
Output: ["()"]
```

## Constraints

- 1 <= n <= 8
