## Problem

Given an array of meeting time intervals, find the minimum number of conference rooms required.

## Examples

**Example 1:**
```
Input: intervals = [[0,30],[5,10],[15,20]]
Output: 2
```

**Example 2:**
```
Input: intervals = [[7,10],[2,4]]
Output: 1
```

## Constraints

- 1 <= intervals.length <= 10^4
- 0 <= starti < endi <= 10^6
